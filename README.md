# Fire Safety Challenge, for Condon Fire & Safety

A quick browser game (about 3 minutes) for Condon Fire & Safety, Indianapolis. Players spot fire hazards in an office, a restaurant kitchen and a paint shop, pick the right extinguisher, use P.A.S.S. to put the fire out, and hit the kitchen pull station only for a real fire. The end screen links to Condon's service request page and phone number.

Play: https://johnny4958.github.io/condon-fire-game/

## Embed on a website

```html
<div style="max-width:480px;margin:0 auto;aspect-ratio:2/3;">
  <iframe src="https://johnny4958.github.io/condon-fire-game/"
    title="Fire Safety Challenge from Condon Fire &amp; Safety"
    style="width:100%;height:100%;border:0;border-radius:12px;"
    allow="autoplay; web-share; clipboard-write" loading="lazy"></iframe>
</div>
```

`index.html` is the whole game in one file, with fonts and logo built in.
